# Spec: 探索页清除筛选功能

## 问题

探索页选择风格/情绪筛选后，没有「清除筛选」按钮，用户想回到全部内容需要手动点击「全部」或清除 URL 参数。

## 解决方案

### 1. 单选移除标签

已选中的 genre/mood 显示为 `bg-primary` 样式，右侧带 `×` 按钮：

- 点击 `×` 只移除该筛选，保留其他筛选和搜索关键词
- 使用 `Link` 组件包裹，内部用 `Button` 处理 `×` 点击（阻止冒泡到 Link）

### 2. 清除全部筛选

当有任一筛选生效时，显示「全部清除」链接：

- 点击后回到 `/explore`（清除所有 genre、mood、q 参数）
- 位置：筛选区的底部，Genre 和 Mood 之间或之后

### 3. 行为规则

| 场景 | 结果 |
|------|------|
| 无任何筛选 | 不显示清除入口 |
| 只有 genre 选中 | 显示 genre 的 `×` 按钮 +「全部清除」 |
| genre + mood 都选中 | 两个都显示 `×` 按钮 +「全部清除」 |
| 有搜索词 | 保留搜索词，只清除筛选 |

### 4. UI 结构

```
筛选区结构：
├── 搜索框（已有清除 q 的按钮）
├── Genre 筛选
│   ├── [全部]
│   ├── [Jazz ×]    ← 选中态 + 关闭按钮
│   ├── [Rock]
│   └── ...
├── Mood 筛选
│   ├── [全部]
│   ├── [Happy ×]   ← 选中态 + 关闭按钮
│   └── ...
└── 全部清除 (条件显示)
```

## 改动文件

| 文件 | 改动 |
