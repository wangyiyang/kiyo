# 用户创作区侧边栏导航设计

## 概述

为 Kiyo AI 音乐创作平台的用户创作区（歌曲、歌词、专辑、设置等页面）添加侧边栏导航，与首页/公开页面保持一致的顶部导航形成差异化布局。

## 目标

- 提升登录用户在创作区的导航体验
- 提供快捷操作入口
- 保持移动端响应式适配

## 页面分区策略

| 区域 | 页面 | 导航类型 |
|------|------|----------|
| 公开/首页 | `/`, `/explore`, `/login`, `/register` | 顶部导航栏 (SiteHeader) |
| 用户创作区 | `/songs`, `/lyrics`, `/albums`, `/settings` | 侧边栏导航 |

## 侧边栏设计

### 布局结构

```
┌──────────────────────────────────────────────────────┐
│  [Logo] Kiyo                                         │
├──────────────────────────────────────────────────────┤
│  ┌─ 快捷操作 ─────────────────────────────────────┐  │
│  │  🎵 新建歌曲                                    │  │
│  │  ✍️ 新建歌词                                    │  │
│  └────────────────────────────────────────────────┘  │
│  ┌─ 导航 ─────────────────────────────────────────┐  │
│  │  🏠 首页                                        │  │
│  │  🎵 歌曲                                        │  │
│  │  ✍️ 歌词                                        │  │
│  │  💿 专辑                                        │  │
│  └────────────────────────────────────────────────┘  │
│  ┌─ 底部 ─────────────────────────────────────────┐  │
│  │  ⚙️ 设置                                        │  │
│  │  🚪 退出                                        │  │
│  └────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────┘
```

### 规格参数

| 元素 | 桌面端 | 移动端 |
|------|--------|--------|
| 侧边栏宽度 | 240px | 100vw（抽屉式） |
| Logo 区高度 | 64px | 64px |
| 快捷操作卡片 | 内边距 12px，圆角 12px | 同左 |
| 导航项高度 | 44px | 44px |
| 侧边栏背景 | `bg-card` / 深色模式适配 | 同左，带遮罩层 |

### 视觉样式

#### Logo 区
- 左侧 Logo 图标（现有 Music2 图标）
- "Kiyo" 文字，font-semibold
- 点击返回首页

#### 快捷操作区
- 背景：`bg-gradient-to-br from-kiyo-purple/10 to-kiyo-cyan/5`
- 边框：`border border-kiyo-purple/20`
- 按钮样式：Ghost 风格，hover 时背景微变

#### 导航项
- 默认：透明背景，图标 + 文字
- Hover：`bg-muted/50`
- 激活：`bg-kiyo-purple/10`，左侧 3px 紫色边框

#### 底部区域
- 上方分隔线：`border-t border-border`
- 设置/退出：文字按钮风格

### 移动端行为
- 侧边栏默认隐藏（translate-x）
- 右上角新增汉堡菜单按钮（在页面内，不依赖 SiteHeader）
- 点击触发侧边栏滑入
- 背景遮罩 `bg-black/50`

## 组件清单

| 组件 | 路径 | 说明 |
|------|------|------|
| `DashboardSidebar` | `components/dashboard-sidebar.tsx` | 主侧边栏组件 |
| `DashboardLayout` | `app/[locale]/dashboard/layout.tsx` | 新的布局包装器 |
| 汉堡菜单按钮 | 各页面通用 | 触发侧边栏 |

## 实施步骤

1. 创建 `DashboardSidebar` 组件
2. 创建 `/dashboard` 布局文件
3. 将 `/songs`, `/lyrics`, `/albums`, `/settings` 移动到 `/dashboard` 下
4. 为移动端添加汉堡菜单触发器
5. 移除旧页面的多余样式
6. 测试响应式行为

## 技术要点

- 使用 CSS Grid/Flexbox 实现主布局
- 侧边栏 `position: fixed` 在桌面端
- 移动端使用 transform 动画
- 保持与现有 SiteHeader 的设计语言一致
- 复用现有国际化翻译 key

## 风险与注意事项

- 需要更新路由配置
- 确保 SEO 页面（songs detail 等）的 metadata 不受影响
- 移动端侧边栏遮罩点击关闭
